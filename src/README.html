How to build AAPS
Simple instructions

This guide explains how to make an AAPS file for your phone.

You do not need to know anything about computers.

You only have to click, and wait.

What you need before you start

  • A PC with Windows 10 or Windows 11
  • Free disk space: 30 GB
  • An internet connection
  • Time: about an hour the first time

Nothing needs to be installed first. The program downloads everything it needs by itself.

The steps

1
The files have already been unpacked into a folder called AAPS.
It sits next to the file you clicked.

You can move that folder wherever suits you. Documents is a fine place.
No Administrator rights needed. It copes on its own even if the folder is inside OneDrive, and even if your user name uses non-English letters.
2
Do you already have aaps-keystore.jks from a previous build?
Do you also have keystore.properties? Copy that one too.

Note exactly where they go:
Both files must sit next to Build-AAPS.bat
and NOT inside the folder AAPS-Builder-Files

If you do put them inside by mistake, the program notices and moves them back out for you.
If you have no key at all, that is perfectly fine. A new one will be created.
3
Double-click the file:
Build-AAPS.bat
A black window opens with a lot of text. That is normal.
4
A window opens with a legal disclaimer.
Read it to the end.

Tick the checkbox that says
"I have read and understood the above, and I accept full responsibility."

Only then does the I Agree button light up. Click it.
The other button is "I Do Not Agree" - it closes everything and builds nothing.
This window appears on every run. That is deliberate.
5
The program asks you one question:

1 = phone app
2 = smartwatch app
3 = both

Press the number, then Enter.
Most people choose 1.
6
Does your key file hold several keys?
A numbered list appears. Press the number of the key, then Enter.

Important: pick the SAME key you used last time, or the phone will refuse to install the update.

If there is only one key, you are asked nothing.
If that key has its own separate password, you will be asked for it too.
7
If you have no key, you are asked to invent a password.
Type a password, then type it again.
Nothing appears on screen while you type. That is normal.
Write the password on paper and keep it.
8
Now wait.
Go and do something else. The first time takes about an hour.
Do not close the black window.
9
When it finishes the window says DONE in green, and a folder opens showing the new file.

Where the files must sit

It should look like this:

AAPS\
 |
 |-- Build-AAPS.bat          <-- you click this
 |-- TEST-FIRST.bat
 |-- README.html
 |
 |-- aaps-keystore.jks       <-- HERE!
 |-- keystore.properties     <-- HERE!
 |-- AAPS-phone-....apk
 |
 \-- AAPS-Builder-Files\     <-- leave alone

Both key files sit next to Build-AAPS.bat.

Not inside AAPS-Builder-Files.
Not in some other folder.

That is deliberate - so you see them, and remember to back them up.

But do not settle for the copy that lives here - copy them somewhere else entirely as well.

Finished. What now?

The folder now holds a file named roughly like this:

AAPS-phone-3.4.2.6-2026-08-17.apk

Move that file to your phone.
By USB cable, by emailing it to yourself, or via Google Drive.

On the phone, tap the file and confirm the installation.

Very important. Do not skip this

After the build, next to Build-AAPS.bat there are two files:

aaps-keystore.jks
keystore.properties

Copy both of them somewhere else - outside this folder!

Why outside the folder?
Because if you delete the AAPS folder to free up space, or the PC dies, or you replace the PC - the key is gone forever.
There is no way to recover it. Not for anyone.

Copy it where? To at least two of these:

  • A USB stick
  • Google Drive / Dropbox
  • Email it to yourself
  • Another computer at home

A copy that lives only inside the AAPS folder on the same PC is not a backup.

Why?
Next time you update AAPS, the phone checks that it is the same key.

If the key is lost, the phone will not let you install the update.
You would have to uninstall AAPS and lose all your settings and history.

And do not send these files to anyone. Whoever holds them can sign apps as you.

How do you update next time?

Before anything else, check both files are in place:

aaps-keystore.jks and keystore.properties
must be next to Build-AAPS.bat.

If they are not there, a NEW key is created - and the phone will refuse the update.

Exactly the same. Double-click Build-AAPS.bat.

It downloads the new version of AAPS by itself, checks by itself whether newer tools are needed, and uses your key by itself.

The second time is much faster.

Something did not work?

  • Look at the last lines in the black window.
  • The folder AAPS-Builder-Files contains build-log.txt. Send it to whoever is helping you.
  • Most problems are solved like this:
    Open AAPS-Builder-Files,
    delete aaps-tools and AndroidAPS inside it,
    and run it again.

Never delete aaps-keystore.jks!

And before deleting anything, make sure a copy of the key exists somewhere else, outside this folder.

What is in the folder?

You should see only these:

  • Build-AAPS.bat - the thing you click
  • README.html - this page
  • AAPS-Builder-Files - a folder. Do not touch it.

After the build these are added:

  • The APK file
  • aaps-keystore.jks - your key
  • keystore.properties - your password

Everything else - the tools, the source code, the logs - is hidden inside AAPS-Builder-Files so it does not confuse you.

A few more things

  • Android Studio is not needed. It is never used.
  • Administrator rights are not needed.
  • Nothing is installed into Windows. Everything stays inside this folder.
  • Want it all gone? Just delete the folder. (Save the key first!)

AAPS is a system that delivers insulin.
Building the file is only the beginning.
